# Лулу мессссссссссссссселдежерер — защищенный мессенджер (old internet 90s)

> **Жесткие требования выполнены:**
> - ❌ Никаких фейковых пользователей, ботов, рекомендаций друзей, серверов-заглушек — только реальные люди
> - 👤 Обязательная уникальная аватарка (загрузка/смена в 1 клик)
> - 💬 Текст + фото + видео в реальном времени (Socket.io + multer)
> - ✓✓ Статусы доставки/прочтения только от реальных собеседников
> - 🔑 Регистрация/вход **без пароля и без email** — только логин
> - 🎙️ Голосовые чаты — специально **без шумоподавления, 8 kbps**, хриплый low-fi как по диал-апу

## Быстрый старт локально
```bash
npm install
npm start
# http://localhost:3000
```

## Структура
```
server.js           — Express + Socket.io + better-sqlite3
public/
  index.html        — UI в стиле Windows 98 / ICQ
  style.css         — 90s дизайн + 7 режимов
  app.js            — логика чатов, WebRTC voice, игры
  music/*.mp3       — твои 4 трека (.png → .mp3 уже конвертированы)
data/lulu.db        — SQLite (WAL) — сохраняется на диске
uploads/avatars/    — аватары
uploads/media/      — фото/видео из чатов
```

## Деплой на Render — как сохранить данные и почистить логи

### 1. Залить на GitHub и подключить к Render (Web Service)
- Build: `npm install`
- Start: `npm start`

### 2. Подключить Persistent Disk (критично!)
В Render Dashboard → Service → **Environment** → **Add Disk**:

| Name | Mount Path | Size |
|------|------------|------|
| `lulu-data` | `/opt/render/project/src/data` | 1 GB |
| `lulu-uploads` | `/opt/render/project/src/uploads` | 1 GB |

> **Что это дает:** `data/lulu.db`, `uploads/avatars`, `uploads/media`, контакты, группы, айди — **сохраняются даже после обновления/редеплоя**. Без диска Render стирает файлы при каждом деплое!

Альтернатива — один диск на `/opt/render/project/src` (если тариф позволяет).

### 3. Логи — чистятся, данные — нет
- Логи идут только в `stdout` (Render Logs) и не пишутся на диск → ротируются автоматически
- Локально почистить: `npm run clean-logs` (удаляет только `logs/*.log`, БД не трогает)

## API
- `POST /api/auth/login` `{username}` — вход/создание без пароля
- `POST /api/avatar` — смена аватарки (multipart)
- `GET /api/users/search?q=` — поиск только реальных (точное совпадение)
- `POST /api/contacts/add` `{username}`
- `GET /api/chats` / `POST /api/groups/create`
- `GET /api/messages/:chatId` / `POST /api/messages`

## Режимы (кнопки справа)
- 🌈 Обычный 90s (Windows 98)
- 😈 Злая версия (красный, глитч)
- 💀 Андертейл (черный, пиксельный, "решимость")
- 🌙 Ночное видение (зеленый NVG, сканлайны)
- 🐱 Нянькет (розовый, котики)
- 🍄 Психоделика (hue-rotate, wobble)
- 🤣 Мемасики (Impact, желтый)

## Мини-игры

- **Лови яйца** — ← → или мышь/тач, корзинка ловит яйца

## Музыка
4 трека уже в `/public/music/` (твои .png переименованы в .mp3). Плеер — WinAmp-стайл. Добавить еще — просто кинуть .mp3 в папку и дописать в `app.js`.

## Безопасность / изоляция
- Нет seed-ботов, нет рекомендаций — `contacts` только ручные
- Нет серверов-заглушек — все сообщения в SQLite, WebSocket только между реальными сокетами
- Валидация логина, токен = user.id (упрощено по ТЗ; для продакшена заменить на JWT)
